1365: // applied at a certain fixed rate.  The DAP portion of Luminary or Colossus
1366: // applies a digital filter to the counts, in order to eliminate electrical
1367: // noise, as well as noise caused by vibration of the spacecraft.  Therefore,

113: /*
114:  * Compose a 4 byte "Packet for Socket Implementation of AGC I/O System" from a
115:  * given channel number and data, and put it into a ringbuffer for later
116:  * processing by yaAGC.
117:  *
118:  * `data` is 15 bits.
119:  *
120:  * `channel` is 9 bits, composed of:
121:  *
122:  * - Bit 0-6:  Port number `p`.
123:  * - Bit 7:    Type bit `t`. If set, this packet is an "unprogrammed counter
124:  *             increment".  If unset, this packet will write `data` to the
125:  *             port.
126:  * - Bit 8:    Mask bit `u`. If set, the data is set as a bit mask for the
127:  *             given port number.  Does not influence the state of the CPU.
128:  *
129:  * See https://www.ibiblio.org/apollo/developer.html
130:  *
131:  * You can call this function up to RINGBUFFER_ELEMENTS times at once before
132:  * the ring buffer is full. Some or all of the packets in the buffer will be
133:  * processed at the next call to `cpu_step`.
134:  *
135:  * Returns 0 when then ringbuffer was full and no write took place. You then
136:  * need to re-try later.
137:  *
138:  * Returns a positive number if the write was successful.
139:  *
140:  * Returns a negative number if a packed could not be formed.
141:  */

143: packet_write (uint16_t channel, uint16_t data)
144: {
145:   unsigned char packet[4];
146: 
147:   if (FormIoPacket (channel, data, packet))
148:     return -1;
149: 
150:   return ringbuffer_put (&ringbuffer_in, packet);
151: }

156:  *
157:  * The return value is a single integer number which is the combination of the

159:  *

162:  *
163:  * If 0 is returned, the ringbuffer was emtpy, and the value can be discarded.
164:  * To keep the ringbuffer depleted, call this function and process the return
165:  * values repeatedly until 0 is returned.
