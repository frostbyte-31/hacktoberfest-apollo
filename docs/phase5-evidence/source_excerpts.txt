1363: // The case of PCDU or MCDU triggers being applied to the CDUX,Y,Z counters
1364: // presents a special problem.  The AGC expects these triggers to be 
1365: // applied at a certain fixed rate.  The DAP portion of Luminary or Colossus
1366: // applies a digital filter to the counts, in order to eliminate electrical
1367: // noise, as well as noise caused by vibration of the spacecraft.  Therefore,
1368: // if the simulated IMU applies PCDU/MCDU triggers too fast, the digital
1369: // filter in the DAP will simply reject the count, and therefore the spacecraft's
1370: // orientation cannot be measured by the DAP.  Consequently, we have to 
1371: // fake up a kind of FIFO on the triggers to the CDUX,Y,Z counters so that
1372: // we can increment or decrement the counters at no more than the fixed rate.
1373: // (Conversely, of course, the simulated IMU has to be able to supply the 
1374: // triggers *at least* as fast as the fixed rate.)
