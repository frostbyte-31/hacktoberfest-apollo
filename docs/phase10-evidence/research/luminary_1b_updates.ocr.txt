3. Definitions 
(a) The index is the total number of data lines (a data line 
being a 5-octal character uplink word group) in the update. For the 
state vector update the index must be equal to 1710, transmitted as 
000213. 
(b) The quantities beginnin g with the state vector identifier 
will be placed, in sequence, into erasable memory beginning at the lo­
cation specified by the starting address. The address must be in an 
"ECADR" form. 
(c) The state vector identifier is used to indicate which 
vehicle state vector is to be update d and where the coordinate system 
is centered. This is accomplishe d by setting the identifier to one 
of the following values.

(d) The position and velocity components must be in reference 
(Besselian) coordinates (may be either geocentric or selenocentric) with 
the time referenced to the computer clock.
